# Un-advance is a separate menu option, not folded into "Jump to lesson..."

Issue #77 proposed "Un-advance" (step a student back exactly one lesson), which is functionally a special case of "Jump to lesson..." (#44) — that picker can already move a student to any position, including backward. We kept both as separate right-click menu options rather than dropping Un-advance in favor of "just use Jump to lesson for that too." Advance/Un-advance are one-click shortcuts for the single-step case that dominates day-to-day marking (mirroring each other symmetrically); Jump to lesson is the general-purpose tool for landing on an arbitrary lesson. Collapsing the two would save a menu item but cost a fast, picker-free interaction for the common case, and would read as inconsistent given Advance (single-step forward) already exists as its own control outside the menu.
