# Review-marking for non-current lessons gets its own menu item, not folded into "Jump to lesson..."

For #76, flagging a lesson other than a student's current one (see [ADR-0011](0011-review-flag-becomes-per-lesson.md)) needed a picker of every lesson in the subject — which "Jump to lesson..." (#44, [ADR-0007](0007-un-advance-kept-separate-from-jump-to-lesson.md)) already renders. We considered adding flag checkboxes to that existing picker instead of introducing a new menu item. We decided against it, for the same reason ADR-0007 kept Un-advance separate from Jump to lesson: the two actions are different shapes — jumping moves the student's position, flagging doesn't — and conflating them would blur whether checking a box while browsing also meant to move the student there. "Review other lessons" is a new, separate right-click option on the Progress Cell, opening its own flag-only picker with no jump action inside it.
