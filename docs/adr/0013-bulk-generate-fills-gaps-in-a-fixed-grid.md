# Bulk Generate fills gaps in a fixed unit×lesson grid, rather than appending new units

For #143 (Bulk Generate), we considered making "N units × M lessons" mean "append N more units after whatever already exists in this subject." We rejected that in favor of treating the input as a fixed grid: unit 1 through N, lesson 1 through M within each unit, always anchored at unit 1. For every `(unit, lesson_in_unit)` cell in that grid without a live lesson, Bulk Generate creates one titled "Untitled" with an empty description; any cell that already has a live lesson is left completely untouched. This lets a teacher use Bulk Generate on a subject that already has some lessons -- to backfill placeholders for the rest of a unit, or add units beyond what exists -- without needing to know or care what's already there.

A cell occupied only by a soft-deleted lesson counts as empty, same as `createLesson` already treats it (#135/[ADR-0010](0010-soft-deleted-lessons-join-the-unique-index.md)): Bulk Generate inserts a fresh row there via the unmodified `createLesson`, and leaves the old soft-deleted row alone. We considered instead restoring (un-deleting) that row and resetting its title/description, but rejected it -- there's no restore/undelete logic anywhere else in this codebase, and restoring would permanently overwrite whatever content the lesson had before it was removed with no way to recover it. Matching the existing insert-only behavior keeps Bulk Generate free of any new, single-purpose mutation path.

Commits immediately on submit, no preview. Undo is a one-shot, whole-batch revert: the ids of lessons created by that batch are held in component state, and Undo soft-deletes all of them via the normal `deleteLesson` call -- the same mechanism and lifecycle as Bulk Advance's undo ([ADR-0005](0005-bulk-progress-advance-is-scoped-to-one-subject.md)). It's cleared the moment any other lesson-affecting action happens on the Curriculum page (add, edit, remove -- bulk or single), and doesn't survive navigating away or a page refresh.
