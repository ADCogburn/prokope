# Subject quick-link to Curriculum uses a distinct icon (📝), not the rename pencil

#187 asked for a "pencil edit icon" on the Class Board panel header that jumps to the Subject's Curriculum page. Reusing ✎ there would collide with what ✎ already means elsewhere in the app: `SubjectNameLabel`'s rename control on the Curriculum page `<h1>` (`showPencil`, #102) and `SubjectReorder`'s reorder-mode toggle both use ✎ to mean "rename/reorder this in place." Clicking the Class Board panel's icon doesn't rename or reorder anything — it navigates away to a different page — so the same glyph would mean two different actions depending on which screen it was clicked from, which is confusing at a glance and worse for anyone leaning on the icon shape rather than reading the (also-shared-sounding) label text.

We use 📝 (memo) instead, kept to the same plain-Unicode-glyph convention as the rest of the app's icon buttons (✎, ✓, ×, 📖) — no icon library introduced. The new control gets its own `aria-label="Edit curriculum for {subject name}"`, distinct from the existing `"Rename subject"` label, so the distinction holds for screen reader users as well as sighted ones. See #191 for the full spec and #195 for the implementation.
