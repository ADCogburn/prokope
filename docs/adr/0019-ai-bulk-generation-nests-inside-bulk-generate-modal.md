# AI Bulk Generation nests inside the Bulk Generate modal, behind an Auto-generate toggle

For #159 (AI Bulk Generation's Curriculum-page entry point), we considered giving AI Bulk Generation its own header button and modal, parallel to "+ Add lesson" and "Bulk Generate" -- the two features share no input fields (a free-text curriculum name vs. unit/lesson counts) and have different submit semantics (an awaited network call vs. an instant local write). We rejected that in favor of nesting it inside the existing `BulkGenerateModal`: a new "Auto-generate" button above the "Units" label swaps the modal's manual form for an AI screen (curriculum-name input, "Generate" button), with a "Back" link to return to the manual form. This keeps both flavors of "make a bunch of lessons appear at once" under one entry point rather than growing the header into a third button, at the cost of the modal now doing meaningfully more than any other modal in this codebase: two independent submit flows, an in-flight network request, and cancel/confirm handling.

That added weight is why closing or backing out of the AI screen while a request is in flight needs an explicit confirm step -- a dialog matching `RemoveLessonDialog`'s shape, not a native `confirm()` -- rather than dismissing silently the way the manual form (an instant local write with nothing to interrupt) always has.
