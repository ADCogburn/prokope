# Class Templates ship save-only; loading is deferred to future class-management work

A Class Template can be saved from the Class Board as of #147, but nothing loads it back onto a class yet. Loading would need to create a new Class row and let the old one live alongside or be deleted, and today's app has no UI to create a second Class or delete the current one at all (`deleteClass` exists only at the db layer, exercised by tests) — building that is out of scope for #147, deferred to a later class create/delete/switch feature that Class Template loading will slot into. Subject Templates don't have this gap: an empty Subject is already reachable via the existing subject-creation flow, so Subject Template save-and-load both ship now, with loading folded directly into subject creation rather than added as a separate step afterward — picking a template prefills the new Subject's name and populates its Lessons in one action.
