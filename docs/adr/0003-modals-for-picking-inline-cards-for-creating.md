# Modals are reserved for picking among existing items; creation and data-entry forms use inline-expanding cards

`SubjectPickerModal`, `LessonPickerModal`, and `RemoveStudentDialog` all use a modal because each one lists existing items for the teacher to choose from or confirm against. `AddLessonCard` and `SkipLessonsPanel`, by contrast, are forms for entering new data (a new lesson; a new skip exception), and both use the inline-expanding-card pattern (collapsed button that expands in place) rather than a modal. This ADR formalizes a convention that was already consistently followed and referenced in code comments (`LessonPickerModal.tsx`, `RemoveStudentDialog.tsx`, `SkipLessonsPanel.tsx`) as "ADR-0003" before this file existed. New UI should default to this split: picking/selecting among existing records opens a modal; creating or entering new data expands inline. See [ADR-0008](0008-add-lesson-card-becomes-a-modal.md) for a deliberate, narrow exception.
